# URL Shortener Frontend

Simple React + Vite frontend for the URL Shortener backend.

Quick start (PowerShell):

```powershell
cd frontend
npm install
npm run dev
```

- The app will run by default at `http://localhost:5173` (Vite). It sends POST requests to `http://localhost:5000/api/url`.
- Make sure your backend is running at `http://localhost:5000` and allows CORS.
